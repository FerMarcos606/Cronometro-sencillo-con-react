⏱️ Cronómetro Sencillo con React y Vite
¡Bienvenido al repositorio de mi proyecto de cronómetro! Este es un cronómetro simple, construido con React y Vite, que te permite iniciar, pausar/reanudar y reiniciar el tiempo con solo unos clics.

✨ Características
Inicio/Pausa/Reanudación: Controla el flujo del tiempo con un solo botón intuitivo.

Reinicio: Vuelve a cero en cualquier momento para empezar de nuevo.

Interfaz Limpia: Un diseño minimalista para una experiencia de usuario sin distracciones.

🚀 Tecnologías Utilizadas
Este proyecto ha sido desarrollado utilizando las siguientes tecnologías:

React: Una biblioteca de JavaScript para construir interfaces de usuario.

Vite: Una herramienta de construcción frontend de próxima generación que ofrece una experiencia de desarrollo rapidísima.

HTML: Para la estructura básica de la aplicación.

CSS: Para estilizar el cronómetro y los botones.
